# 演义发布包使用说明

演义在本机运行，浏览器用于阅读与设置。首次运行自动导入两部示例；发布包的 `examples/` 也附有可导入的 zip。`schemas/` 提供作品编辑器补全定义。

## 选择与启动

Windows 选择 `windows`，macOS 选择 `darwin`，Linux 选择 `linux`；Intel / AMD 常见电脑使用 `amd64`，Apple 芯片与 ARM 设备使用 `arm64`。

解压到可写的普通目录。Windows 双击 `yanyi.exe`，或在 PowerShell 运行 `./yanyi.exe`。macOS / Linux 在终端进入解压目录后运行 `./yanyi`，必要时先执行 `chmod +x yanyi`。程序会打开浏览器；没有自动打开时访问终端显示的地址。关闭终端或按 Ctrl+C 停止服务。

macOS 首次运行未公证的程序可能被拦截。确认下载来自演义仓库并核对校验和后，尝试启动一次，再进入「系统设置 → 隐私与安全性」，找到该程序并选择「仍要打开」，重新运行并确认。不要关闭整个系统的安全检查；步骤参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

SHA-256 校验和在发布页的 `checksums.txt`。Windows 可用 `Get-FileHash <压缩包> -Algorithm SHA256`，macOS 可用 `shasum -a 256 <压缩包>`，Linux 可用 `sha256sum <压缩包>`。

## 数据与升级

数据默认存放在可执行文件旁的 `yanyi-data/`，也可以通过 `serve --data <目录>` 指定。设置页「存储」可查看实际路径。这里包含模型密钥、访问密码记录、作品和存档：**不要分享整个数据目录，也不要把它放在网盘同步目录里运行**。备份时先停止演义，再复制完整数据目录。

升级前停止程序并备份数据，解压新发布包，**只替换可执行文件**；保留原数据目录与启动参数。开发预览阶段的数据结构可能调整，升级前同时阅读对应发布说明。不要在同一数据目录同时启动两个实例。

分享作品用作品详情的「导出 zip」或 `yanyi work pack <作品目录>`，不要分享运行时数据。删除内置示例后不会在重启时恢复，可随时导入发布包附带的示例 zip。

## 局域网与访问密码

默认只监听本机。设置页「访问与分发」可设置密码和监听地址；监听地址重启后生效，`serve --listen` 优先于设置。监听 `0.0.0.0` 后可用本机局域网 IP 从其他设备访问。服务开放后，登录者可操作作品、存档并使用已配置的模型额度。

密码修改会退出所有设备。忘记密码时先停止服务，在终端运行 `yanyi password clear --data <数据目录>`；重新设置可用 `yanyi password set --data <数据目录>`，密码通过隐藏输入读取，不写入命令行历史。自动化可用 `--stdin`，不要把密码写入脚本或发布包。

此服务没有内置 TLS，建议只在受信任的本机或局域网环境访问。
