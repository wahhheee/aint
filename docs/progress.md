## 怎么用

**状态**只用下面五种写法（便于搜索与统计）：

| 标记 | 含义 |
| --- | --- |
| ✅ 完成 | 达到任务的产出要求；可能还有标了编号的小尾巴，写在"缺口"里 |
| 🟡 部分 | 有可用的实现，但缺口明显 |
| 🧱 骨架 | 只有接口、类型、路由或占位，调用时返回"尚未实现" |
| ⬜ 未开始 | — |
| ⛔ 受阻 | 依赖外部条件（如 API Key），条件写在"缺口"里 |

**按任务找代码**：每个未完成点都带任务编号——`TODO(M3-1)` 注释、未实现的工具 `notYet("read", "M3-1")`、返回 501 的路由
`todo("…（M3-1）")`。搜编号即可列出全部相关位置（正则排除 M3-10、M3-11）：

```bash
git grep -nE "M3-1([^0-9]|$)"
```

**更新规则**（人和 AI 都按这个来）：

1. 推进了某个任务：改[任务明细](#5-任务明细)中该行的状态、已有、缺口 → 改[总览](#1-总览)计数 → 在[进度日志](#8-进度日志)顶部加一条（日期、内容、提交）→ 改本文顶部的"最后核对"。
2. 标 ✅ 之前用上面的命令看一遍该编号剩下的 TODO，确认都是可以接受的小尾巴，并写进"缺口"。
3. 代码里新增未完成点写 `TODO(任务编号)：说明`；找不到合适任务的，记入[已知问题](#7-已知问题与技术债)。
4. 需要用户拍板的事记到 [open-questions.md](notes/open-questions.md)，已确认的决策在 [decisions.md](notes/decisions.md)。

## 2. 现在能用什么

`task dev` 后访问 <http://localhost:5173>（假模型，不需要 API Key）；`task dev:server:real` 使用设置中配置的真实模型：

- **书架与作品**：两部内置示例（《雾港来信》《第一个故事》）、线装书封面、作品详情（简介 / 存档 / 版本 / 校验报告）、开局设置（开局表单、模型、篇幅、推理）；
  **导入作品**：zip、文件夹、GitHub（含分支与子目录）或 HTTPS 链接，先校验再确认，同内容复用已有版本；版本页支持检查更新、查看更新说明、导出与删除
- **阅读页**：静态与生成式开场、流式正文与打字机、选项（数字键）、自由输入与输入模式、斜杠命令面板与作品命令（含确认）、`/ooc` 场外对话、
  停止（保留已生成内容）、截断自动续写、作品可选的正文结束后选项补调用（`features.force_choices`，默认关闭）、断线重连与续传、面板（侧栏 / 顶栏 / 浮动 / 抽屉，状态变化时即时刷新）、舞台背景与场景标题卡、
  插图卡片、样式标签、骰子卡片、作品主题与 custom.css、图片附件（选择或粘贴）、阅读设置
- **真实模型**：Anthropic Messages、OpenAI Responses、Gemini 三个协议（含中转站与 DeepSeek 等兼容接口）；推理块原样回传、缓存断点、
  图片与工具结果含图、截断续写；AI 可以用 read / list / search 查阅作品资料、记忆与原文（`/transcript`）、看图（常驻图片、素材、玩家上传），
  用 write / edit / remove 维护记忆，用 get_state / update_state 维护状态，用 roll_dice 掷骰
- **长篇游玩**：上下文达到预算时自动整理（玩家阅读期间进行，此时的输入排队）：执笔者先把要紧的事写进记忆，再写交接摘要，最近几个回合原样保留；
  回合内达到上限或模型报超限时紧急整理；手动整理（用量环中的按钮、`/compact`）；同模型整理或轻量模型独立整理；顶栏用量环显示上下文与阈值
- **用量与费用**：用量环的浮层显示本回合各类 token（未缓存 / 缓存读取 / 写入 / 输出 / 推理）与费用、本存档累计费用与其中整理的花费；
  费用按模型价格的货币分别列出（不做汇率换算），价格未配置时显示"未配置价格"；`GET /usage` 按存档、作品、节点或全局汇总
- **分支**：回合操作菜单（重新生成、修改正文、修改我的输入、回到此处、复制）、版本切换 ‹ i/n ›、回到更早回合后的新分支提示、丢弃中断的回合；
  时间线与分支抽屉（切换、删除分支、复制为新存档）；记忆抽屉（查看、编辑、新建、删除，修改在下一回合告知执笔者）；状态抽屉（开发者工具）
- **设置**：阅读与外观（实时预览）、上下文（预算、保留原文、整理方式）、存储位置、开发者选项、关于；**模型**：添加供应商向导（协议 → 地址与密钥 → 勾选或手动添加模型 →
  连接测试）、价格倍率、模型设置（窗口、能力、推理映射、缓存方式、价格）、设为主笔、设为轻量模型
- **创作者工具**：链接本机开发目录、递归监听与去抖校验，成功后原地更新开发版本并推送页面；10 个 JSON Schema 与编辑器配置说明。命令行：`aint serve`、`work init`、`work validate [--json]`、`work pack`（确定性 zip）、`work prompt`、`password`、`version`
- **升级与存储**：存档选择目标版本后先整理再迁移，旧分支保留；新字段取默认值，不兼容旧值可在迁移记录中查看。删除受存档与历史分支保护，设置页可清理无引用存储；删除内置示例后不自动恢复
- **访问与分发**：访问密码、登录与节流、退出全部设备、监听地址与局域网无密码警告；六平台发布包含可执行文件、使用说明、Schema 与示例 zip
- **游玩参数与演出**：游玩中切换模型 / 推理与预算、左侧回合目录、触屏长按菜单、插图大图、音频 / 停顿 / 限时选项；默认关闭的后台助手与标题生成。
- **调试**：游玩页独立开关与可收起的侧边检查器；实时查看每次调用的执行过程、模型明文推理、上下文、工具参数与结果、状态差异、VFS 前后快照、脱敏 HTTP 请求与响应（含重试）；可搜索、复制、跟随最新、按回合筛选；假模型脚本（`--fake-llm`）、磁盘追踪（`--trace-llm`）、日志关联 ID（见 [development.md](development.md) 第 3 节）

**还不能用**：作品与全局的用量统计页；示例定稿、教程版文档与发布候选版验收尚未完成。
