## 术语

| 术语 | 含义 |
| --- | --- |
| 作品 | 可分发的执笔指令、设定、开场、状态、命令、界面与素材 |
| 作品版本 | 一份作品文件快照，通常以文件树哈希标识；开发目录使用可更新的开发版本 |
| 存档 | 一次游玩，绑定作品版本，包含回合、状态、记忆与分支 |
| 回合 | 从一次输入到模型交还控制权的过程，可包含多次模型调用 |
| 节点 | 存档树中的开局、回合、整理、编辑或补选项记录 |
| 当前进度 / head | 存档当前指向的节点；从根节点到它的路径称为进度线 |
| 主笔 / 执笔者 | 负责故事正文、资料查阅、状态和记忆维护的模型 |
| 轻量模型 | 可选模型，用于标题、后台助手或独立整理 |
| 上下文整理 | 将较早回合中的要点写入记忆并生成交接摘要，保留近期原文 |
| 阶段块 | 整理后上下文中的交接摘要、状态快照与记忆目录 |
| VFS | 模型通过工具访问的文件系统，包含作品、记忆、原文与上传图片 |
| 开发目录 | 链接到本机文件夹的作品，文件变化后自动校验和重载 |
| 作品能力版本 | 程序支持的作品能力集合，作品用 `engine` 声明适用范围；当前为 `2.0` |
