# AINT 使用说明

AINT 在本机运行，浏览器用于阅读与设置。首次运行自动导入《倒悬的街角》和《第一个故事》；发布包的 `examples/` 也附有可导入的 zip。`schemas/` 提供作品编辑器补全定义。

## 选择与启动

目前仅验证 Windows 平台的实际运行，具体为 Windows/amd64；Windows/arm64、macOS 和 Linux 的实际运行待验证。

Windows 选择 `windows`，macOS 选择 `darwin`，Linux 选择 `linux`；Intel / AMD 常见电脑使用 `amd64`，Apple 芯片与 ARM 设备使用 `arm64`。

解压到可写的普通目录。Windows 双击 `aint.exe`，或在 PowerShell 运行 `./aint.exe`。macOS / Linux 在终端进入解压目录后运行 `./aint`，必要时先执行 `chmod +x aint`。程序会打开浏览器；没有自动打开时访问终端显示的地址。关闭终端或按 Ctrl+C 停止服务。

macOS 首次运行未公证的程序可能被拦截。确认下载来自 AINT 仓库并核对校验和后，尝试启动一次，再进入「系统设置 → 隐私与安全性」，找到该程序并选择「仍要打开」，重新运行并确认。操作步骤参见 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

SHA-256 校验和在发布页的 `checksums.txt`。Windows 可用 `Get-FileHash <压缩包> -Algorithm SHA256`，macOS 可用 `shasum -a 256 <压缩包>`，Linux 可用 `sha256sum <压缩包>`。

## 配置模型与开启存档

1. 打开「设置 → 模型」，选择添加供应商，填写协议、API 地址与密钥。支持 Anthropic Messages、OpenAI Responses 和 Gemini，以及提供这些协议的兼容服务。
2. 拉取模型列表或手动填写模型 ID，运行连接测试。模型需要支持工具调用；含图片的作品可选择支持看图的模型。
3. 将模型设为主笔。轻量模型可用于独立整理、后台助手和存档标题，在对应设置中开启功能。
4. 返回书架，打开作品并新建存档。选择开场，填写作品提供的开局表单，调整模型、篇幅与推理档位后开始。

模型调用使用你配置的 API，服务商按其规则计费。可在模型设置中填写价格，用量环显示当前回合与存档累计费用；不同货币分别统计。尚未配置价格的模型会显示“未配置价格”。

## 导入与管理作品

书架「导入作品」支持 zip、文件夹、公开 GitHub 仓库和 HTTPS 下载链接。解析后显示作品信息与校验报告，确认后加入书架。GitHub 链接可包含分支与子目录，高级选项可单独填写这两项。

作品详情的版本页提供检查更新、导出和删除。存档绑定开启时的作品版本；导入新版本后，在存档菜单选择升级，先整理已有故事，再迁移状态，旧分支保留。开发目录用于创作，保存文件后自动校验和重载。

删除整部作品会同时删除其版本、存档和分支，界面会先显示确认。单独删除版本时，会检查是否有存档或历史分支引用它。

## 阅读与分支

点击选项或使用数字键推进故事；作品允许自由输入时，也可以直接描述行动。输入 `/` 查看内置命令与作品命令，`/ooc 内容` 用于与执笔者讨论故事。正文生成期间可以停止，普通续写会保存已有内容。

回合菜单提供重新生成、按要求重写、修改正文、修改输入和回到此处。重新生成和重写保留多个版本，可用版本按钮切换；回到较早回合后继续会产生新分支。时间线抽屉可切换分支，也可复制为新存档。

阅读设置可以调整字体、字号、行距、打字机和限时选项。作品配置音频时可调整音量或静音。记忆抽屉支持查看和编辑模型记下的资料；用量环显示上下文规模，达到预算后自动整理，也可手动整理。整理期间的新输入会排队。

## 切换开场

- 开场本身不计入玩家首轮；中断开场的“继续”也属于开场。
- 开场后，第一次玩家触发的模型回复成功保存时，存档永久锁定开场。选项、自由输入、作品命令、继续和场外对话均计入。
- 生成、整理或事件连接尚未同步时，切换入口暂时禁用。停止、失败、超时或回合预算耗尽不视为成功完成。
- 切换清除存档中的试读历史与分支，重建初始状态、记忆和开场；不保留旧开场的状态变化或手动编辑。有未完成的玩家互动时先提示确认。
- 保留存档名称、开局表单、模型及游玩设置；已产生的用量继续归属于原存档。生成式开场切换回来会重新生成，选择当前项不重新开始。
- 锁定不随回退、删除分支或作品升级解除；复制存档继承所选开场与锁定状态。其他开场通过新建存档体验。

## 重写与补选项

- `/rewrite 要求`：按要求重写当前进度的最后一个故事回合。回合菜单的「按要求重写」提供同一功能。要求为 1–8000 字；「重新生成」则使用原输入再次生成。
- `/choices`：为当前回合生成选项。正文末尾没有选项时也显示「生成选项」按钮。与作品的 `features.force_choices` 设置独立，不改变后续回合是否需要选项。

重写生成期间，正文原位显示新版草稿。成功后成为当前版本，原版可以通过版本按钮切回。取消、模型出错、拒答、预算耗尽或没有有效正文时丢弃草稿，恢复原版。生成式开场可以重写；静态开场保留作品原文，可补选项。只有场外回应、没有故事正文的回合不适用这两个操作。

补选项期间保留当前正文。成功后选项附在这篇正文下，刷新页面仍可选择；选择或自由输入沿用普通续写流程。已经存在选项时不重复生成。选项的数量、内容、行动方向与文风由模型结合作品决定，平台不附加剧情创作规则。

两个操作都需要当前存档没有生成或整理任务。多页面使用时，目标回合与当前进度同时校验；旧页面的请求会被拒绝并重新同步。

## 数据与升级

当前版本暂不支持程序自动更新和存档导出。更新程序需手动下载发布包；备份存档需停止 AINT 后复制完整数据目录。

数据默认存放在可执行文件旁的 `aint-data/`，也可以通过 `serve --data <目录>` 指定。设置页「存储」可查看实际路径。这里包含模型密钥、访问密码记录、作品和存档。数据目录放在本机磁盘；备份时先停止 AINT，再复制完整目录。分享作品使用导出 zip。

升级前停止程序并备份数据，解压新发布包，**只替换可执行文件**；保留原数据目录与启动参数。开发预览阶段的数据结构可能调整，升级前阅读对应发布说明。同一数据目录由一个实例使用。

分享作品用作品详情的「导出 zip」或 `aint work pack <作品目录>`。删除内置示例后不会在重启时恢复，可随时导入发布包附带的示例 zip。

## 局域网与访问密码

默认只监听本机。设置页「访问与分发」可设置密码和监听地址；监听地址重启后生效，`serve --listen` 优先于设置。监听 `0.0.0.0` 后可用本机局域网 IP 从其他设备访问。服务开放后，登录者可操作作品、存档并使用已配置的模型额度。

密码修改会退出所有设备。忘记密码时先停止服务，在终端运行 `aint password clear --data <数据目录>`；重新设置可用 `aint password set --data <数据目录>`，密码通过隐藏输入读取，不写入命令行历史。自动化可用 `--stdin` 从标准输入传递密码。

服务通过 HTTP 提供访问，适用于本机或受信任的局域网。
