# 重写与补选项验证


确定性回归在 `internal/runtime/operation_test.go`：原版参考与工具环境隔离、连续分支、后续编辑隔离、过期进度、补选项只读、选项回填与复制编辑、整理、写入后失败与取消、紧急整理整体提交及回滚。前端单元测试覆盖命令、操作重试和会话快照；`web/e2e/operations.spec.ts` 覆盖重写原位替换、刷新后取消恢复、补选项刷新与选择续写。

真实模型评测在 `internal/runtime/operation_live_test.go`，默认跳过。用例从金币 10 的雨夜集市起点重写购买：旧版红伞 2 金币，新版蓝伞 3 金币，再次重写仍应为金币 7；检查记忆不含旧版购买，补选项后状态不变，选择后正常续写。对可见正文和原始普通回复检查确认语、改写说明、执行计划及重复段落，推理块不作为正文判断。

真实测试会产生费用，每步最多 8 次调用、120 秒、单次输出上限 4000 token。私有配置只通过环境变量读取，日志和原始报文放在 `.local/eval/`，不入库。
