# AINT v0.1.0-alpha.1 · 首个预览版

AINT 是在本机运行的 AI 互动小说运行时。导入作品、连接模型 API 后，在浏览器中阅读、选择行动或自由输入；作品、设置和存档保存在本机。

## 当前版本

- 支持 Anthropic Messages、OpenAI Responses、Gemini 三种协议，可配置供应商与模型。
- 支持作品导入、更新与开发目录，内置《倒悬的街角》和《第一个故事》。
- 支持选项与自由输入、重新生成、按要求重写、补充选项、编辑正文及分支切换。
- 支持记忆、状态、上下文整理、音频、用量与费用统计、调试检查器和访问密码。
- 提供作品创作命令、JSON Schema、创作指南和 `aint-work` 技能。

## 验证范围与待完成事项

- **目前仅验证 Windows 平台的实际运行，具体为 Windows/amd64。** Windows/arm64、macOS 和 Linux 提供编译产物，实际运行待验证。
- **暂不支持程序自动更新。** 更新时手动下载新发布包。
- **暂不支持存档导出。** 备份时先停止 AINT，再复制完整数据目录；默认目录为程序旁的 `aint-data/`。
- 长篇真实模型评测与内置示例的内容定稿仍在进行。

## 下载与启动

1. 在[发布页](https://github.com/wahhheee/aint/releases/tag/v0.1.0-alpha.1)的 Assets 下载对应系统与处理器的压缩包。常见 Intel / AMD Windows 电脑选择 `aint_0.1.0-alpha.1_windows_amd64.zip`；Windows ARM 设备选择 `windows_arm64`，macOS 对应 `darwin`，Linux 对应 `linux`。
2. 解压到可写目录。Windows 双击 `aint.exe`；macOS / Linux 在终端运行 `./aint`。程序启动后打开浏览器。
3. 在「设置 → 模型」中添加供应商、填写 API 地址与密钥，并将模型设为主笔。
4. 返回书架，打开作品并新建存档。

模型调用使用所配置的 API，费用由对应服务商收取。发布包附有使用说明、创作指南、技能、10 个 Schema 和两部示例 zip。`checksums.txt` 提供各压缩包的 SHA-256 校验和。

详细操作见[使用说明](https://github.com/wahhheee/aint/blob/v0.1.0-alpha.1/docs/usage.md)，创作作品见[创作指南](https://github.com/wahhheee/aint/blob/v0.1.0-alpha.1/docs/authoring.md)。

## 数据与许可

数据目录包含作品、存档、设置和模型密钥。更新前停止程序并备份完整目录，保留原数据目录与启动参数；后续版本的数据变更事项会写入对应发布说明。

运行时代码、文档和技能采用 Apache-2.0；《倒悬的街角》采用 CC-BY-NC-4.0，《第一个故事》采用 Apache-2.0。
