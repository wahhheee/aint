# AINT v0.2.0-alpha.1 · 记忆整理、Vertex AI 与 Android 支持

本次为开发预览版，新增模型接入与 Android 安装包，并完善长篇游玩的记忆整理和问题排查。

## 本次更新

- 新增 Google Vertex AI，可在「设置 → 模型」中接入 Gemini，支持 API Key、访问令牌和服务账号。感谢 @Mooooooon 在 #2 中的贡献！
- 新增 Android arm64 安装包，供 Termux 使用。
- 完善上下文整理：AI 可以根据已发生的剧情核对和更新故事状态，合并重复记录、清理已结束的事项。
- 完善记忆索引：整理时同步更新记忆要点，开局及整理后的续写可直接参考完整索引中的关键事实与未决事项。
- 新增自动调试记录，默认开启，覆盖生成式开场，便于排查游玩问题；可在「设置 → 开发者选项」中关闭自动开启，也可在游玩顶栏暂停记录。检查器入口移至用量环右侧，方便查看调用记录。

## 更新与下载

在发布页按文件名后缀选择压缩包：常见 Intel / AMD Windows 电脑选 `windows_amd64.zip`，Apple 芯片 Mac 选 `darwin_arm64.tar.gz`，Android arm64 的 Termux 选 `android_arm64.tar.gz`；其他设备按系统与架构选择。

更新前停止程序并备份数据目录，替换可执行文件，保留原数据目录与启动参数。
