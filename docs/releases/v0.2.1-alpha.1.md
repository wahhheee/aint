# AINT v0.2.1-alpha.1 · 模型连接与生成中断修复

- **Windows 模型连接**：修复了开启系统手动代理后，双击启动 AINT 仍可能直连模型服务并超时的问题。
- **Android Termux 模型连接**：修复了部分设备因域名解析失败，无法获取模型列表或连接模型服务的问题。
- **生成中断提示**：主动停止生成，或遇到模型拒答、超时等中断时，输入框上方会说明原因和正文是否已保存。可以重试未保存的输入，也可以重新生成已保留的回合。
- **记忆整理**：修复了整理中断时可能采用不完整结果的问题。如果还没继续游玩，可以直接重试整理。

## 下载与更新

Android arm64 设备请选择以 `android_arm64.tar.gz` 结尾的压缩包。这是供 Termux 运行的命令行程序，不是可以点击安装的 APK。在 Termux 中解压后，进入 `aint` 所在目录，运行 `./aint`。

更新已有版本时，先停止 AINT 并备份数据目录，再替换可执行文件，继续使用原来的数据目录和启动参数。
