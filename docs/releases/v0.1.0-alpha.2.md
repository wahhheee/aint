# AINT v0.1.0-alpha.2 · 上下文档位与费用确认

本预览版增加上下文与保留原文档位，并在启用高预算前提示供应商计费规则。

## 本次更新

- 工作上下文预算新增 **512K** 档位。
- 保留原文新增 **48K** 档位。
- 默认工作上下文预算为 **256K**，默认保留原文为 **24K**。
- 全局设置、开局设置与游玩设置启用超过 256K 的新预算时，提示部分供应商会对超出 256K 的上下文进行双倍收费，确认后才保存。取消或按 Esc 不启用；沿用当前预算无需重复确认。
- 修复设置页窄屏布局，320 px 屏幕可以完整显示上下文档位。

上下文预算仍受模型窗口减去预留的限制，保留原文仍受整理阈值限制。计费以供应商规则为准。

## 更新与下载

在[发布页](https://github.com/wahhheee/aint/releases/tag/v0.1.0-alpha.2)下载对应系统与处理器的压缩包。常见 Intel / AMD Windows 电脑选择 `aint_0.1.0-alpha.2_windows_amd64.zip`；其他平台选择对应的 `windows_arm64`、`darwin` 或 `linux` 包。

更新前停止程序并备份完整数据目录，只替换可执行文件，保留原数据目录与启动参数。本版本没有数据库或作品格式变更；已保存的上下文设置继续生效，新默认值用于尚未配置的设置。程序暂不支持自动更新和存档导出。

发布包包含使用说明、创作指南、aint-work 技能、10 个 Schema 和两部示例 zip。

完整操作见[使用说明](https://github.com/wahhheee/aint/blob/v0.1.0-alpha.2/docs/usage.md)，作品创作见[创作指南](https://github.com/wahhheee/aint/blob/v0.1.0-alpha.2/docs/authoring.md)。
