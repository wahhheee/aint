# 雾港来信

一座被雾封住的港口，一封寄错的信。

你在雾港的邮局醒来，柜台上的煤油灯还亮着，手里攥着一封写给“明天的你”的信。老陈不见了，林舟的袖口有一道新鲜的擦痕，灯塔的光扫过的间隔似乎变了。

## 玩法

- **推论**：在输入栏切换到「推论」模式，提出你的主张。执笔者会依据真相回应——能被否定的，会以金色的**封印陈述**反驳；无法否定的，推论暂时成立。
- **跟随**：用 `/follow 人物` 让叙述转而跟随某个人物，从其视角继续讲述；也可以在**人物**抽屉里点"跟随"。
- **揭晓**：卡住了，或者想看结局时，用 `/揭晓` 请执笔者说出真相。
- 右侧的**笔记本**记录线索、日期与人物对你的信任；**封印**一栏收录所有已被证实的陈述；**人物**抽屉里是你见过的人。
- 结果难料的时刻，执笔者会掷骰（1d20）决定成败。可以把图片（比如一张手绘的推理图）附在行动里给执笔者看。

> 这是 AINT 的内置示例作品，同时也是自动化测试夹具。图片素材由脚本生成，暂未附带音频。
