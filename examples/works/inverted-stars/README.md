# 倒悬的街角

> 鸦羽巷七号事务所。

欢迎来到垂直巨城**「奥尔良」**。

这座城市沿着一道深不见底的大地裂谷内壁层层构筑：
- **头顶百米高空**，三道巨型黄铜与白水晶环轨组成的「日冕天轮」缓缓旋转，白昼折射天光，傍晚将晚霞切碎成逆流向上的金色折光雨；
- **城市正中央**，两百米长的纯银「大静默钟摆」每半个时辰无声掠过半个街区的云雾，震得檐下风铃齐鸣；
- **而在城市正下方**，是一座拥有「倒悬星穹」、「失重浮岛林海」与「寂静琉璃海」的活体生态深渊。

---

## 你是谁

你是中层灰羽街区鸦羽巷 7 号**「灰羽探索事务所」**的年轻所长。

两年前，你从一场被公会列为机密的深渊第四层事故中独自生还，退居二线开了这家不起眼的事务所。你腰间佩着一柄修长的单手直剑，左手则通晓老练实用的深渊刻印与钩索技巧；手边常年放着一枚前任老队长留下的旧黄铜指北针。

在开局时，你可以选择自己的过往底色：
- **深渊第一斥候**：熟稔迷宫地形与魔物习性，中下层的老猎人与酒客都认得你的名号；
- **折光塔叛逃的学者**：精通深渊刻印与古遗迹机关，曾是薇薇安在学院里最熟悉的同门；
- **自上层放逐的没落贵族**：深谙上层贵族的礼仪、剑术与黑话，儿时曾在宫廷宴会上与奥黛丽有过一面之缘。

## 街角与深渊里的她们

街巷中的人物有各自的性格、关系与正在忙碌的事情：

- **克莱尔**：住店搭档兼看板娘。栗色短发，修身皮马甲配百褶短裙与微透深黑连裤丝袜，左大腿绑着飞刀皮环。管着事务所的账本与厨房，嘴上嫌弃你乱花钱，却总给你留着热茶。
- **奥黛丽·冯·兰开斯特**：上层圣咏歌剧院的首席女高音、公爵千金。银白长卷发，夜访中层时宽大斗篷下藏着缀有宝蓝星屑内衬的象牙白短礼裙、印着几何烫金花纹的纯白过膝长袜与银白短靴。
- **薇薇安**：折光塔深渊生态学系的怪才学姐。酒红挽发，细金丝半框眼镜下有一颗小泪痣，敞开的学者黑袍内是高领无袖针织衫、包臀窄裙与微透深黑吊带丝袜。说话慢条斯理，毫无社交距离感。
- **芙蕾雅**：「黑荆棘馆」的女主人兼前白昼近卫团首席女剑士。暖金高马尾配暗银荆棘冠，一身修身暗黑轻甲与高开叉战裙，冰冷的黑铁护腿与战靴下裹着丝滑的半透深黑连裤丝袜。

除了她们之外，你随时可以在街巷、酒馆、歌剧院或深渊中结识全新的角色，她们同样会在奥尔良的日常生活中留下自己的轨迹。

## 游玩提示

- **行动选择**：可以追查委托、探索深渊浮岛，也可以在街区散步、去酒馆闲聊。
- **时间推进**：人物与势力的活动随故事时间发展，通过来信、传闻和街区变化呈现。
- **闲暇小憩**：随时可通过输入栏旁的「小憩」按钮（或 `/小憩`）在安全处度过一段闲适时光，让时辰自然流转。

## 开场与面板

新建存档时可选择「雨停后的鸦羽巷」「失重林海的晴昼」或「黑荆棘馆的微醺夜」，并填写姓名与过往底色。三个开场各自设置时间、地点、人物关系、银币和行囊。

顶栏显示日期、时辰、地点与局势；侧栏记录人物印象、身体状态、银币、随身物品和事务所备忘。可以选择正文下方的选项，也可以自由输入行动，使用 `/ooc` 讨论故事。
